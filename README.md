# Description

In this project the goal was to make a 3D maze using raycasting principles.
We created a game with a dynamic view inside a maze, where you have to find your way.
We made sure that wall collisions are not possible in our maze.
We got to explore windows, colors, events and textures in MLX42.

# Instructions

clone this project, then:

``` make ```

To execute the program:

```./cub3D map/file.cub```

To cleanup:

```make clean```

To cleanup .o files and the executable:

```make fclean```
